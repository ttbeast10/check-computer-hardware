# check-computer-hardware

סקריפט לבדיקת מחשב נייד יד שנייה (Windows 10/11) לפני קנייה.
הוא בודק את החומרה, מציג דגלים אדומים ושומר דוח לקובץ טקסט.

## מה נבדק

| # | בדיקה | פרטים |
|---|-------|-------|
| 0 | מערכת | יצרן, דגם, מספר סידורי, גרסת BIOS |
| 1 | מעבד | דגם מדויק, ליבות פיזיות, נימים (threads), מהירות בסיס |
| 2 | זיכרון RAM | נפח, סוג (DDR4/DDR5...), מהירות, חריצים תפוסים |
| 3 | כוננים | דגם, נפח, NVMe/SATA, SSD/HDD, מצב בריאות, בלאי, שעות פעולה, שגיאות |
| 4 | סוללה | קיבולת מקורית מול נוכחית, אחוז בריאות, מחזורי טעינה + דוח היסטוריה HTML |
| 5 | Windows | גרסה, האם מופעל, סוג רישיון, **האם המחשב מנוהל ע"י ארגון** (מחשב חברה/גנוב) |
| 6 | עומס CPU | 30 שניות עומס מלא שבו **כל חישוב נבדק מול תשובה ידועה** (כמו Prime95), טמפרטורות לפני/שיא/אחרי, זיהוי Throttling וירידת מהירות |
| 7 | זמן פעילות | מאז ההפעלה האחרונה |
| 8 | היסטוריית תקלות | 90 יום אחורה: מסכים כחולים (עם הסבר על הסיבה), שגיאות חומרה (WHEA), כיבויים פתאומיים, שגיאות כונן, ניקוי יומן |
| 9 | בדיקת זיכרון | כתיבה ובדיקה של דפוסים ב-60% מהזיכרון הפנוי, כ-45 שניות |

בסוף: סיכום עם **דגלים אדומים**, אזהרות, המלצה, ורשימת בדיקות ידניות (מסך, מקלדת, פורטים...).

## שתי גרסאות — בחר אחת

| קובץ | צריך פייתון? | הערות |
|------|-------------|-------|
| `Run-LaptopCheck.bat` + `laptop_check.ps1` | **לא** | הכי פשוט אצל המוכר — לחיצה כפולה |
| `laptop_check.py` | כן (בלי `pip install`) | אותן בדיקות, משתמש רק בכלים מובנים של Windows |

## הוראות הרצה אצל המוכר (בלי פייתון)

1. **בבית:** העתק לדיסק-און-קי את `Run-LaptopCheck.bat` ו-`laptop_check.ps1` (באותה תיקייה).
2. אצל המוכר: **חבר את המטען** וסגור תוכנות פתוחות.
3. חבר את הדיסק-און-קי, פתח אותו ב-File Explorer ולחץ **לחיצה כפולה** על `Run-LaptopCheck.bat`.
4. אם מופיע "Windows protected your PC" — לחץ **More info → Run anyway**.
5. אשר את חלון **"Do you want to allow this app to make changes"** (הרשאות מנהל — נדרשות לנתוני SMART וטמפרטורות).
6. חכה כ-3 דקות. אל תשתמש במחשב בזמן בדיקת העומס ובדיקת הזיכרון.
7. קרא את ה-**SUMMARY** בסוף. הדוח (`laptop_report_*.txt`) ודוח הסוללה (`battery-report_*.html`) נשמרים בדיסק-און-קי.

## הרצה עם פייתון

```
python laptop_check.py
```

אפשרויות: `--seconds 60` (עומס ארוך יותר), `--skip-stress` (בלי בדיקת עומס), `--skip-memtest` (בלי בדיקת זיכרון), `--memtest-seconds 120`, `--history-days 180`, `--no-admin`.

בגרסת PowerShell: `-Seconds 60`, `-SkipStress`, `-SkipMemTest`, `-MemTestSeconds 120`, `-HistoryDays 180`.

## דגלים אדומים עיקריים

- כונן: סטטוס לא Healthy, בלאי ≥90%, שגיאות לא מתוקנות, סקטורים פגומים, אזהרת SMART
- סוללה: בריאות מתחת ל-60%, מעל 800 מחזורים, או סוללה שלא מזוהה
- Windows לא מופעל
- המחשב מנוהל ע"י ארגון (Domain / Entra ID / Intune / Autopilot) — ייתכן שהוא רכוש של חברה וייחסם מרחוק
- טמפרטורה ≥95°C או מעבד שרץ מתחת ל-50% ממהירות הבסיס בעומס (התחממות / מאוורר / סוללה בלויה)
- פחות מ-4GB RAM
- מסך כחול שמצביע על חומרה (למשל `MEMORY_MANAGEMENT`, `WHEA_UNCORRECTABLE_ERROR`), שגיאת חומרה קטלנית, או bad block ביומן
- בדיקת הזיכרון מצאה שגיאות
- המעבד החזיר תוצאה שגויה בבדיקת העומס (לא יציב: התחממות, שינוי מתחים או מעבד/זיכרון תקולים)

אזהרות (צהוב): יומן אירועים שנוקה, 3+ כיבויים פתאומיים, שגיאות CPU/זיכרון שתוקנו, בריאות סוללה 60–80%, בלאי כונן ≥60%, כונן HDD מכני, 4–8GB RAM, הפעלת Windows דרך KMS (לרוב מפעיל פיראטי), טמפרטורה ≥88°C.

## מגבלות שכדאי לדעת

- **טמפרטורה:** הרבה מחשבים ניידים לא חושפים את חיישן המעבד ל-Windows. במקרה כזה הסקריפט יגיד זאת. למדידה מדויקת אפשר להוסיף לדיסק-און-קי את [HWiNFO Portable](https://www.hwinfo.com/download/) או LibreHardwareMonitor.
- **SMART מלא:** אם `smartctl.exe` (מחבילת [smartmontools](https://www.smartmontools.org/)) נמצא באותה תיקייה עם הסקריפט או מותקן — הסקריפט יקרא גם סקטורים פגומים, כמות נתונים שנכתבה ועוד.
- **זמן פעילות:** כש-Fast Startup פעיל, "כיבוי" לא מאפס את הזמן — רק "הפעלה מחדש".
- **חריצי RAM:** ניידים לא תמיד מדווחים מספר חריצים מדויק, וזיכרון מולחם מופיע כמודול.
- **בדיקת זיכרון:** בודקת רק את הזיכרון הפנוי (Windows ותוכנות פתוחות תופסים את השאר), ותופסת תקלות קבועות. לבדיקה מלאה: [MemTest86](https://www.memtest86.com/) מדיסק-און-קי (שעה ומעלה).
- **היסטוריה:** תלויה ביומן של Windows — אם הוא נוקה או שה-Windows הותקן מחדש, אין היסטוריה. הסקריפט מציין עד מתי היומן מגיע.
- **תאריך התקנה:** מתאפס גם בעדכון גרסה גדול של Windows, לא רק בהתקנה נקייה.
